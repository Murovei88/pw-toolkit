# PW Toolkit

**PW Toolkit** — open-source веб-приложение для игроков официального сервера Perfect World.

## Особенности
- Поддержка модулей: Душа Пань Гу, Звёздный диск, Джинн, книги, карты, титулы
- Автоматический пересчёт характеристик
- Сохранение и загрузка билдов по уникальному ID

## Технологии
- Backend: Go, MariaDB, Redis, MinIO
- Frontend: React + TypeScript
