# PW Toolkit

**PW Toolkit** — локально разворачиваемое open-source веб-приложение для игроков официального сервера Perfect World (RU). Основная цель — предоставить современный инструмент для создания, анализа и сравнения билдов персонажей.

## Особенности
- Выбор класса, уровня, экипировки
- Поддержка модулей: Душа Пань Гу, Звёздный диск, Джинн, книги, карты, титулы
- Автоматический пересчёт характеристик
- Сохранение и загрузка билдов по уникальному ID

## Технологии
- Backend: Go, MariaDB, Redis, MinIO
- Frontend: React + TypeScript
- Оркестрация: Docker Swarm
